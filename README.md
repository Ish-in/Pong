# Pong
A pong game created with HTML, css, and Javascript. Created to help me learn the basics of all three languages.
Ai was not used at all, but online tutorials such as blog posts have been utilised in order for me to learn how to make this game. I do not know all the blog post owners but I anyways want to thank them for the inspo. and teaching me what to do. As this game is pretty much complete, i have no need to further update. 

The controls for this game are :
left up - W
left down - S
Right up - ArrowUp
Right down - ArrowDown
